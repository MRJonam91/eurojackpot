# Eurojackpot

Una base per consultare ed esplorare le estrazioni Eurojackpot.

## Stato del progetto

Il progetto è in preparazione: questa repository raccoglie lo storico e la documentazione iniziale.

## Dati e fonti

`storici/ej.csv` contiene 1.005 estrazioni dal 23 marzo 2012 al 20 novembre 2026. Fonte: [Lottochaos](https://lottochaos.com/en/open-data/), licenza [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Verifica i risultati con i bollettini ufficiali.

Le estrazioni sono casuali: frequenze e risultati passati non permettono di prevedere quelli futuri.
